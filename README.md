# 📺 iptv-player-bangla

[![IPTV Player](https://img.shields.io/badge/type-iptv%20player-blue)](https://github.com/tunnabri-ops/iptv-player-bangla)
[![Language](https://img.shields.io/badge/UI-Bangla-orange)](https://github.com/tunnabri-ops/iptv-player-bangla)

**Lightweight static IPTV player — paste a single channel's M3U8 link and press Play.**

> বাংলা সংস্করণ নিচে আছে। / Bangla version below.

## ✨ Features

- **Single-channel HLS playback** — `index.html` plays any `.m3u8` stream in the browser (hls.js)
- **Channel groups** in `channels.json` — Bangla, News and Sports
- **EPG link included** in `channels.json`, so the player can show what's on now and next.
- **No auto-play trap** — the page does not try to play a playlist file as a video

## 🚀 How to use

1. Open `index.html` in a browser.
2. Paste one channel's `.m3u8` link and press **Play**.
3. For the full channel list, open the playlist file in VLC or any IPTV player.

## ⚠️ Honest limits

- A **playlist file itself will not play** — only a single channel stream plays in this page.
- This is a lightweight static starter: no favourites list and no on-screen EPG guide yet.
